How to find 50 prospects

  1. Google Maps: search “electrician Pretoria East” (then Centurion, Midrand, Randburg, Boksburg…).
  2. Open each listing. Keep it if: 4.0+ rating, 10+ reviews, real phone number.
  3. Shortlist if: no website, old/broken website, or no WhatsApp/quote button.
  4. Run each through Prospect audit → save to tracker.
  5. Message 1-by-1 using the scripts. Follow up after 2–3 days.
